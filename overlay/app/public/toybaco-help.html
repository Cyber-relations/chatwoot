ログインで困ったとき

ログイン前でも、こちらで手順を確認できます。

パスワードがわからない

登録したメールアドレスで再設定します。メールが届いたら、新しいパスワードを設定してください。

パスワードを再設定
確認メールが届かない

登録したアドレスと迷惑メールを確認してください。ログイン時にメール確認を求められたら、その画面から再送できます。

ログイン画面へ
店舗が表示されない

招待を受けたメールアドレスでログインしているか確認してください。招待されていない場合は、店舗の管理者にメンバー追加を依頼します。

画面の読み込みが終わらない

通信状態を確認し、未保存の原稿があれば手元に控えてから画面を読み込み直してください。続く場合は、別のブラウザーでログイン画面を開きます。

会話・受信トレイ

  1. 「会話」からチャンネルや担当者で対象を絞り、会話を開きます。
  2. 返信欄で宛先・本文・添付を確認して送信します。社内の記録には「プライベートメモ」を使います。
  3. 対応が終わったら会話を解決済みにします。接続先の追加・変更は「設定 → 受信トレイ」で行います。

担当者・チーム

「設定 → 担当者」でメンバーを管理し、「設定 → チーム」で担当するグループを設定します。受信トレイの担当者設定も確認してください。追加できる人数は契約の利用枠によって異なります。

連絡先

「連絡先」で検索し、連絡先の詳細から会話履歴やメモ、カスタム属性を確認します。連絡先の編集と会話への返信は別の操作です。

自動化・マクロ・定型文

「設定 → 自動化」で実行条件とアクションを指定します。保存前に対象チャンネルと条件を確認してください。「マクロ」は会話で手動実行する一連の処理、「定型文」は返信欄に取り込む文章です。

投稿・共有プレビュー

  1. 「投稿」を開き、必要なSNSを「チャンネルを追加」から接続します。
  2. 「投稿を作成」で本文・画像・動画を準備し、投稿先ごとのプレビューを確認します。
  3. 下書き保存と公開・予約は別の操作です。公開できる権限、投稿先、公開日時を確認して実行します。
  4. 共有プレビューでは内容確認とコメントができます。リンク先でコメントのログインを求められた場合はトイバコIDを利用します。

公開に失敗した投稿は、カレンダーの失敗表示から理由と対処を確認します。再実行の前に、SNS側にも投稿済みでないか確認してください。

メディア・投稿設定

「投稿 → メディア」でファイル名による検索、プレビュー、アップロードを行います。「投稿設定」では時刻表記や通知、RSS、投稿テンプレート、署名を設定できます。投稿結果は「分析」で確認します。

メッセージテンプレート

「設定 → テンプレート」では受信トレイに同期されたテンプレートを確認します。WhatsAppのテンプレートはMetaまたはTwilioで作成・変更し、トイバコで「テンプレートを同期」を押して一覧を確認してください。投稿のテンプレートは「投稿 → 投稿設定」で管理します。

Webチャットの本人確認

サイトの開発担当者向けの設定です。「設定 → 受信トレイ → 対象のWebチャット → 設定」で本人確認用のキーを確認できます。

  1. サイトのサーバー側で、キーとログイン済みユーザーIDからHMAC-SHA256の16進署名を生成します。
  2. 埋め込みSDKのsetUserに同じIDを渡し、identifier_hashに署名を指定します。名前・メールアドレス・画像URLのうち少なくとも1つも渡してください。
  3. キーはブラウザへ渡さず、署名のあるユーザーと署名のないユーザーの動作を確認してから本人確認を必須にします。

設置作業は、サイトの管理者・開発担当者に依頼してください。本人確認用のキーを操作の質問に貼り付けないでください。

ヘルプセンター

ヘルプセンターを利用できるアカウントでは、ポータルを作成し、カテゴリと記事を整理して公開します。外観設定ではトイバコの初期色から変更できます。独自ドメインの接続は、サイトの管理者にDNS設定を依頼してください。利用できる機能は契約画面で確認できます。

AIの使い方

「AIアシスタント」から問い合わせ返信と投稿文作成の入口を選びます。返信AIの動作は現在の設定に従います。下書きモードと全自動モードを取り違えないよう、設定画面で確認してください。投稿文AIの文案は、本文や投稿先を確認してから保存・公開します。

SNSの接続・制限

接続が制限されている場合は、画面に表示された理由を確認してください。Facebook・Instagram・WhatsAppのサービス状況はMetaの公式ステータスで確認できます。接続先SNSの障害とトイバコ側の接続制限は異なります。

再接続は、店舗の管理者が対象の窓口の設定で行います。画面に表示された理由を確認してください。パスワードや認証コードを使い方の質問に貼り付ける必要はありません。

契約・お支払い

「設定 → ご契約内容」で契約を確認します。支払い方法や請求履歴の操作は、トイバコのお支払い画面から案内される決済画面で行います。変更には契約者の権限が必要です。

お知らせ・サポート

サービスの案内はトイバコのお知らせで確認できます。アプリに「使い方を調べる」が表示される場合は、作業中の画面から操作の手順を確認できます。
